# DeltaRetro

*This project is currently unfinished!*

# Dependencies

* Raylib `v5.6` ([repo](https://github.com/raysan5/raylib.git))
* tomlc17 ([repo](https://github.com/cktan/tomlc17.git))

If you are trying to build this project, you'll need to install Raylib on your system!
More information over at the [Raylib repo](https://github.com/raysan5/raylib.git).

# Description

DeltaRetro is an attempt at ~~recreating more or less accurately~~ creating something similar to the *Link's Awakening* inspired game featured in *Deltarune Chapter 3*.
